# ScopeBuddy enclosure

[`ScopeBuddy.stl`](ScopeBuddy.stl) is the printable enclosure model for the
Elecrow CrowPanel Advance 5-inch ScopeBuddy hardware.

- Format: binary STL
- Units: millimeters
- Overall model dimensions: approximately 97 × 159.9 × 46 mm
- SHA-256: `a4a02c17bde15460220753ae9005e1edd779837a3d6084155f440077f7377692`

Import the model into a slicer without scaling. Choose print orientation,
supports, layer height, and material settings to suit the printer and filament. I recomend "fuzzy skin" to match the print bed structure at the front of ScopeBuddy.

I simply put a small dab of hot glue in each corner of the display and used that to secure it inside the enclosure. So far, it's been more than sufficient, and it's easy to remove if needed. I'd originally planned to use heat-set inserts. However, the PCB's mounting holes are so close to the edge of the display that there's no room for them if you want the display to sit flush with the front of the enclosure. If you have a better idea, please let me know :)
